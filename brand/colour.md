# Colour

Direction B, *Orchard at dusk* (`decisions.md`, 7 November 2026), with the dark theme's ground from reference 004 (8 November). Every value lives in `tokens.json`; this page says what each is for. The app reads them as CSS variables of the same names (`src/tokens.css`), and the `/brand` screen shows every swatch with its live ratio.

## The idea

Cool soil greys under a bright leaf green. Fig purple and pomegranate red are the two accents and mean the two crops, nothing else. In the dark theme the ground is deep green, not grey: dusk in the orchard. One colour per kind of diary entry, the same in both themes, so "the orange one" is always the pest count.

## One colour per kind of entry

| Kind | Token | Kind | Token |
| --- | --- | --- | --- |
| Growth stage | `fig` | Pollination | `slate` |
| Spray | `bad` | Forecast | `indigo` |
| Fertiliser | `primary` | Crop check | `warn` |
| Irrigation | `water` | Crop estimate | `olive` |
| Pruning | `teal` | Harvest | `brown` |
| Pest count | `orange` | Day's pick | `berry` |
| Lab result | `violet` | | |

The kind's colour sits on the tile's edge and its icon, and fills the tile at the `-soft` tint; the text on a tint is always `ink` or `muted`. `src/styles.css` → `.k-…` sets `--hue` and `--fill` once; everything else reads those.

## Rules

- Text is at least 4.5:1 on what it sits on; icons, edges and chart marks at least 3:1. Every pair is listed in `tokens.json` → `$extensions.feno.pairs` and `src/lib/tokens.test.ts` fails the build if one drops below its floor in either theme.
- Never colour alone: a red notice has an alert icon, a chosen tab has a label, a chart has a table.
- Never write a hex in `styles.css` or a component. Add a token, a pair, and run `npm run tokens`.
- The mark's plate is `primary` of the light theme in both themes; the mark never changes with the theme (`logo.md`).
- Windows High Contrast drops every fill: the chosen state keeps a border and a line under the words (`styles.css` → forced colours).

## Primitives

The `color` groups in `tokens.json` (`leaf`, `soil`, `ink`, `gold`, `red`, `fig`, `pom`, the nine kind hues, `white`, `shadow`) hold every raw value, named by hue and a step that orders them from light to dark. Nothing in the app refers to a primitive; only the roles above do. A new colour is a new primitive first, then a role that points at it.
